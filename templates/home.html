Strategic Overview

ทิศทางยุทธศาสตร์ & ผลลัพธ์การเรียนรู้

มุ่งเน้นการสร้างผลลัพธ์การเรียนรู้เชิงทักษะ คุณธรรมจริยธรรม และการพัฒนานวัตกรรมดิจิทัลเพื่อพัฒนาท้องถิ่นสู่ระดับสากล

PROGRAM PHILOSOPHY

"เชี่ยวชาญด้านวิทยาการคอมพิวเตอร์ มีคุณธรรม นำนวัตกรรมเพื่อพัฒนาท้องถิ่น"

ปรัชญาของหลักสูตรสะท้อนอัตลักษณ์สำคัญ 3 ด้าน ได้แก่ ความเชี่ยวชาญในวิชาชีพคอมพิวเตอร์ · การมีคุณธรรมจริยธรรมวิชาชีพ · และ การนำนวัตกรรมไปประยุกต์ใช้เพื่อการพัฒนาท้องถิ่นอย่างยั่งยืน สอดรับกับเป้าหมายของมหาวิทยาลัยราชภัฏศรีสะเกษในการเป็นสถาบันอุดมศึกษาแห่งการเรียนรู้ตลอดชีวิต

เรียนรู้จากการปฏิบัติจริง

ฝึกพัฒนาแอปพลิเคชัน โค้ดดิ้ง และโครงงานนวัตกรรมในห้องปฏิบัติการคอมพิวเตอร์มาตรฐานสูง

คณาจารย์ดูแลใกล้ชิด

อาจารย์ผู้เชี่ยวชาญเฉพาะทางคอยให้คำแนะนำและการบ่มเพาะองค์ความรู้อย่างทั่วถึง

เครือข่ายสหกิจศึกษา

โอกาสฝึกงานและทำงานร่วมกับองค์กรชั้นนำและบริษัทซอฟต์แวร์ระดับประเทศ

วิสัยทัศน์ที่เกี่ยวข้อง (Vision)

มุ่งร่วมเป็นกำลังสำคัญขับเคลื่อนมหาวิทยาลัยให้เป็น "สถาบันอุดมศึกษาแห่งการเรียนรู้ตลอดชีวิต" (Lifelong Learning Institute) โดยการผสานจัดกระบวนการศึกษาและวิจัยเพื่อสร้างสรรค์นวัตกรรม บูรณาการเรียนการสอนเข้ากับการลงมือทำงานจริงเพื่อความเจริญเติบโตอย่างยั่งยืนของท้องถิ่น

1. ผลิตบัณฑิตคุณภาพ

สร้างสรรค์บัณฑิตที่มีทักษะความรู้ด้านวิทยาการคอมพิวเตอร์และเทคโนโลยีขั้นสูง พร้อมตอบโจทย์การปฏิบัติงานจริงในทุกองค์กรยุคใหม่ได้อย่างมืออาชีพ

2. วิจัยและนวัตกรรม

ส่งเสริมวิชาการ ค้นคว้าวิจัยประยุกต์ และพัฒนานวัตกรรมผลิตภัณฑ์ทางด้านคอมพิวเตอร์ที่สอดคล้องกับแนวทางการแก้ปัญหาทางเทคโนโลยีของท้องถิ่น

3. บริการวิชาการท้องถิ่น

พัฒนาสมรรถนะนักศึกษาในการเรียนรู้ร่วมกับสังคม ก้าวสู่การเป็นนักพัฒนาเทคโนโลยีและวิศวกรสังคมที่มีหัวใจมุ่งรับใช้และช่วยเหลือชุมชน

4. คุณธรรมและกฎหมาย

หล่อหลอมความซื่อสัตย์สุจริต การเคารพในกฎหมายทรัพย์สินทางปัญญา ลิขสิทธิ์ซอฟต์แวร์ และปฏิบัติตามจรรยาบรรณวิชาชีพนักไอทีอย่างมั่นคง

OBJ 1

มีความรู้ความเชี่ยวชาญและทักษะเฉพาะด้านในสาขาวิทยาการคอมพิวเตอร์อย่างลึกซึ้ง สามารถออกแบบ พัฒนา และบำรุงรักษาระบบซอฟต์แวร์เชิงประยุกต์ทั้งรูปแบบออนไลน์และออฟไลน์ได้อย่างดีเลิศ

OBJ 2

มีทักษะในการประยุกต์ใช้วิธีวิทยาและเทคโนโลยีในการพัฒนางานวิจัย โครงงานนวัตกรรม และแอปพลิเคชันรูปแบบใหม่ที่ช่วยเสริมสร้างศักยภาพและการเพิ่มมูลค่าทางเศรษฐกิจให้แก่ชุมชนท้องถิ่น

OBJ 3

มีความเป็นเลิศในการวิเคราะห์และประมวลองค์ความรู้ทางเทคนิคแบบบูรณาการ เพื่อการวางแผนจัดสรรกระบวนการทางคอมพิวเตอร์และสารสนเทศแก้ปัญหายากเชิงซ้อนภายในองค์กรได้อย่างมีขั้นตอน

OBJ 4

ยึดมั่นในการประพฤติตนเป็นคนดีมีระเบียบวินัย ปฏิบัติตามหลักจรรยาบรรณวิชาชีพนักวิทย์คอม พร้อมทั้งมีมนุษยสัมพันธ์และทักษะการทำงานร่วมกับผู้อื่นได้อย่างสร้างสรรค์ประณีต

PLO1 · K3

ประยุกต์ใช้ความรู้ด้านวิทยาการคอมพิวเตอร์เพื่อแก้ปัญหาและสนับสนุนการทำงานด้วยระบบคอมพิวเตอร์ได้อย่างถูกต้องตามสถานการณ์ของปัญหา

PLO2 · K4,S3

พัฒนาระบบด้วยโปรแกรมภาษาต่าง ๆ ในรูปแบบออฟไลน์และออนไลน์ ตามกระบวนการวิเคราะห์และออกแบบระบบได้อย่างถูกต้องตามเกณฑ์มาตรฐานสากล

PLO3 · K4,S3

พัฒนาแอปพลิเคชันที่ทำงานบนโมบายอุปกรณ์พกพาได้ถูกต้องตรงตามความต้องการและเกิดประสบการณ์ที่ดีกับผู้ใช้งานจริง

PLO4 · K4,S3

ทดสอบคุณภาพการทำงานของซอฟต์แวร์ตามกระบวนการตรวจสอบแบบ Black Box Testing และ White Box Testing ได้อย่างถูกต้องและได้มาตรฐานเทคนิค

PLO5 · K4,S3

พัฒนานวัตกรรมด้านเทคโนโลยีคอมพิวเตอร์ที่สอดคล้องกับความต้องการของชุมชนและหน่วยงานท้องถิ่นด้วยกระบวนการวิจัยและพัฒนาอย่างเป็นระบบ

PLO6 · A3

แสดงออกถึงกระบวนการคิดเชิงระบบ ความเป็นมืออาชีพ มีความอดทน มุ่งมั่น และรับผิดชอบสูงต่ออุปสรรคและปัญหาในการดำเนินงานทางด้านเทคโนโลยี

PLO7 · A2

แสดงถึงการตระหนักและประยุกต์ใช้หลักจรรยาบรรณวิชาชีพ คุณธรรม และจริยธรรมในการปฏิบัติงานตามข้อกฎหมายและ พ.ร.บ. คอมพิวเตอร์อย่างสุจริต

CURRICULUM TRACKS

3 เสาหลักความเชี่ยวชาญเฉพาะทาง

รายวิชาเข้มข้นที่ออกแบบตามมาตรฐานสากลเพื่อสร้างบัณฑิตที่พร้อมทำงานทันทีหลังสำเร็จการศึกษา

โครงข่ายคอมพิวเตอร์

การออกแบบ ติดตั้ง และบำรุงรักษาระบบเครือข่าย ทั้งแบบสายและไร้สายเพื่อการสื่อสารในองค์กร

3 หน่วยกิต · มีแล็ป

ความปลอดภัยข้อมูล

การป้องกันและควบคุมความปลอดภัยของข้อมูล การเข้ารหัสลับ และการตรวจจับภัยคุกคามไซเบอร์

3 หน่วยกิต · บรรยาย

นิติวิทยาศาสตร์ดิจิทัล

การตรวจสอบวิเคราะห์ข้อมูลจากการโจมตีทางไซเบอร์ พยานหลักฐานดิจิทัล และกฎหมายคอมพิวเตอร์

3 หน่วยกิต · มีแล็ป

ระบบฐานข้อมูล

การออกแบบและจัดการระบบฐานข้อมูลเชิงสัมพันธ์ การเขียนคำสั่ง SQL และการจัดการธุรกรรมข้อมูล

3 หน่วยกิต · มีแล็ป

วิศวกรรมซอฟต์แวร์

กระบวนการวิเคราะห์และออกแบบระบบซอฟต์แวร์ การทดสอบ Black/White Box และการบำรุงรักษา

3 หน่วยกิต · บรรยาย

พัฒนาเว็บแอปพลิเคชัน

ปฏิบัติการสร้างเว็บด้วยโมเดิร์นเฟรมเวิร์กยอดนิยม React, Next.js, Node.js และ RESTful API

3 หน่วยกิต · มีแล็ป

ประมวลผลภาพดิจิทัล

การปรับแต่งภาพดิจิทัล การสกัดคุณลักษณะของภาพ และการตรวจจับวัตถุด้วย Computer Vision

3 หน่วยกิต · มีแล็ป

สารสนเทศภูมิศาสตร์

การประยุกต์ใช้เทคโนโลยีสารสนเทศในการวิเคราะห์และแสดงผลข้อมูลแผนที่พิกัดทางภูมิศาสตร์

3 หน่วยกิต · มีแล็ป

ภูมิปัญญาประดิษฐ์

ทฤษฎีและอัลกอริทึมปัญญาประดิษฐ์ การค้นหา การประมวลผลภาษาธรรมชาติ (NLP) และระบบอัตโนมัติ

3 หน่วยกิต · บรรยาย

วิทยาการข้อมูล
